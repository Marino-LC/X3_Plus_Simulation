# X3 Plus - MuJoCo

Modelo para visualización en MuJoCo.

## Instalación
Instalar Python y el paquete mujoco.

```bash
python -m pip install mujoco
```

## Ejecución
Desde esta carpeta ejecutar:

```bash
python -m mujoco.viewer --mjcf=x3plus_mujoco.xml
```

Nota: versión en desarrollo, con rodillos mecanum fijos.
